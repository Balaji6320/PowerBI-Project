# Power BI Projects – Balaji

## 📊 Project Overview
This repository contains Power BI dashboards created to analyze sales,Overall Profit and customer data. The projects focus on transforming raw data into meaningful business insights using interactive visualizations.

## 🛠 Tools & Technologies
- Power BI Desktop
- DAX (CALCULATE, FILTER, SUMX, SWITCH)
- Power Query (Data Cleaning & Transformation)
- SQL (Basic Queries)
- Excel

## 📈 Key Features
- Interactive dashboards with slicers and filters
- Drill-through and tooltip pages
- Bookmark-based page navigation
- WebUrl And And Dynamic ImageUrl
- KPI cards and trend analysis
- Row Level Security (RLS) by category
- Optimized data models (Star Schema)

## 📂 Dashboards Included
- Sales Performance Dashboard
- Customer Insights Dashboard
- Category-wise Revenue Analysis
- Overall Profit Summary

## 🎯 Learning Outcome
- Hands-on experience with real-world Power BI scenarios
- Strong understanding of data modeling and DAX
- Ability to build business-ready dashboards
